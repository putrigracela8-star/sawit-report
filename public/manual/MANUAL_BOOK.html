1. Pendahuluan

1.1 Tentang SawitReport

SawitReport adalah sistem informasi manajemen perkebunan kelapa sawit berbasis web yang membantu operasional harian kebun, manajemen pekerja, gudang & logistik, serta dashboard KPI per afdeling. Dirancang untuk alur kerja mandor, kerani, asisten, dan manajemen.

2. Registrasi & Login

2.1 Membuat Akun Baru

  1. Buka https://sawitreport.online
  2. Klik tombol "Daftar Gratis" pada paket GRATIS
  3. Isi form pendaftaran: Nama Perusahaan, Nama Lengkap, Email, No. Telepon, Password (min 8 karakter)
  4. Klik "Daftar"
  5. Sistem akan otomatis login ke Dashboard

2.2 Login

  1. Buka https://sawitreport.online
  2. Klik "Masuk" di pojok kanan atas
  3. Masukkan Email dan Password
  4. Klik "Login"

2.3 Lupa / Reset PIN

  1. Pada halaman Masukkan PIN, klik link "Lupa PIN?"
  2. Masukkan email terdaftar
  3. Cek inbox email untuk link reset (berlaku 30 menit)
  4. Klik link, masukkan PIN baru (4-12 digit)
  5. Klik "Reset PIN"

3. Dashboard

Dashboard adalah halaman utama setelah login yang menampilkan ringkasan KPI.

3.1 Kartu Ringkasan

  • Panen Hari Ini — Total JJG, tonase (kg), brondolan (kg)
  • Kehadiran — Jumlah hadir / tidak hadir hari ini
  • Stok Kritis — Barang dengan stok di bawah minimum
  • MTD / YTD / MoM — Produksi bulan ini, tahun ini, dan perbandingan bulan lalu

3.2 Filter Lokasi

Gunakan dropdown Kebun dan Afdeling untuk menyaring data.

3.3 Alert

  • Achievement Rendah — Kebun/afdeling dengan capaian < 90%
  • Gap Terbesar — Selisih real vs target terbesar (negatif)
  • Anomali MA-7 — Blok dengan penurunan > 50% dari rata-rata 7 hari (PREMIUM)
  • Stok Kritis — Barang dengan stok di bawah minimum

3.4 Grafik Produksi Bulanan

Grafik batang realisasi produksi vs target per bulan sepanjang tahun.

4. Master Data

Akses: ADMIN — membutuhkan PIN MASTER.

4.1 Kebun

Tambah: Kode (unik) + Nama + Lokasi (opsional) → klik "Tambah"

4.2 Afdeling

Tambah: Pilih Kebun + Kode (unik per kebun) + Nama → klik "Tambah"

4.3 Blok

Tambah: Pilih Afdeling + Kode + Nama + Luas (ha) + Tahun Tanam → klik "Tambah"

Ditampilkan dalam struktur: Kebun → Afdeling → Blok

4.4 Jabatan / Regu

Kode unik + Nama jabatan.

4.5 Kegiatan / Pekerjaan

Digunakan untuk penugasan absensi. Kode unik + Nama + Kategori (opsional).

4.6 Kegiatan Perawatan

Digunakan untuk modul perawatan. Kode unik + Nama + Kategori (opsional).

4.7 Jenis Pupuk

Kode unik + Nama.

4.8 Pekerja / Karyawan

Tambah: NIK (opsional, unik) + Nama + Jenis (TETAP/HARIAN/BORONGAN) + Jabatan (opsional) + Afdeling (opsional) → klik "Tambah"

Pagination: 50 per halaman.

4.9 Budget Produksi Bulanan

Tambah: Pilih Afdeling + Tahun + Bulan (angka 1-12) + Target (ton) + Budget Biaya (opsional) → klik "Simpan"

4.10 Kalender Kerja

Override hari kerja/libur. Default: Senin-Sabtu kerja, Minggu libur.

4.11 Import Data Excel

Akses: Menu Import Data di sidebar.

Format: File .xlsx dengan kolom sesuai tipe data (pekerja, barang, budget). Lihat format detail di halaman Import Data.

5. Operasional Harian

5.1 Panen

Akses: Menu Operasional Panen — PIN INPUT.

  1. Pilih Tanggal dan Afdeling → klik "Tampilkan"
  2. Isi JJG, Tonase (kg), Brondolan (kg), Biaya (opsional), Catatan (opsional)
  3. Klik "Simpan" per baris

5.2 Perawatan

Akses: Menu Operasional Perawatan — PIN INPUT.

  1. Pilih Tanggal dan Afdeling → klik "Tampilkan"
  2. Pilih Kegiatan, Volume, Satuan, Biaya (opsional), Catatan (opsional)
  3. Klik "Simpan"

5.3 Pemupukan

Akses: Menu Operasional Pemupukan — PIN INPUT.

  1. Pilih Tanggal dan Afdeling → klik "Tampilkan"
  2. Pilih Jenis Pupuk, Dosis (kg/ha), Total (kg), Biaya (opsional), Catatan (opsional)
  3. Klik "Simpan"

5.4 Absensi & Penugasan

Akses: Menu Absensi & Penugasan — PIN INPUT.

Absensi: Pilih Tanggal + Afdeling → "Buat absensi" → "Tarik pekerja (auto)" → Atur Hadir/Tidak + Jam Kerja

Penugasan: Pilih Pekerja + Kegiatan + Blok (opsional) + Catatan → "Tambah penugasan" → Isi realisasi JJG/Brondolan → "Simpan"

5.5 Gudang & Logistik

Akses: Menu Gudang & Logistik — PIN INPUT.

Master Barang: Kode + Nama + Kategori + Satuan + Stok Min + Harga Satuan → "Tambah barang"

Transaksi: Tanggal + Tipe (MASUK/KELUAR) + Barang + Qty + Biaya (opsional) + Referensi + Catatan → "Simpan"

Stok kritis ditandai merah. Badge stok kritis muncul di sidebar.

7. Payroll

Akses: Menu Payroll — PREMIUM — PIN REPORT.

7.1 Set Tarif Global

Masukkan Upah/Jam, Tarif JJG, Tarif Brondolan → "Simpan Tarif"

7.2 Generate Payroll

  1. Buat Periode (from + to date + afdeling)
  2. Klik "Generate Payroll" pada periode DRAFT
  3. Sistem menghitung: Upah Harian + Upah Borongan + Bonus - Potongan = Grand Total

7.3 Lock Periode

Klik "Lock" untuk finalisasi. Periode LOCKED tidak bisa digenerate ulang.

7.4 Export

  • Rekap CSV
  • All Slip ZIP (PDF per pekerja)
  • Slip PDF (per pekerja)

8. Budget & Biaya

8.1 Set Budget Biaya

Di Master Data → Budget Produksi Bulanan, isi Budget Panen, Perawatan, Pemupukan, Lain (Rp).

8.2 Halaman Budget vs Real Cost

Akses: Menu Budget vs Real Cost — PIN REPORT.

Tahun + Bulan (opsional) + Afdeling (opsional).

Menampilkan: kartu ringkasan, grafik horizontal, tabel detail per afdeling dengan warna hijau/merah.

Data real cost dari: biaya panen, perawatan, pemupukan, transaksi gudang KELUAR.

9. Laporan & Export

Akses: Menu Rekap & Export — PIN REPORT.

9.1 Filter & Download

Filter: From date + To date + Kebun + Afdeling + Blok → "Terapkan"

Download PDF: Laporan 7 halaman lengkap (cover, ringkasan, produksi harian, panen per afdeling, perawatan & pemupukan, absensi & gudang, ranking, tanda tangan).

Download CSV: Panen, Perawatan, Pemupukan, Absensi, Gudang.

10. Laporan Otomatis (Email)

Akses: Menu Laporan Otomatis — BASIC/PREMIUM — PIN MASTER.

10.1 Atur Jadwal

Aktif + Tanggal Kirim + Jam Kirim + Email Penerima (pisahkan koma) → "Simpan"

10.2 Kirim Manual & Riwayat

Klik "Kirim Sekarang" untuk kirim langsung.

Menu Riwayat Email: lihat log 20 pengiriman terakhir + "Kirim Ulang".

11. Backup & Restore

Akses: Menu Backup Data — BASIC/PREMIUM — PIN MASTER.

11.1 Download

  • ZIP Backup — format JSON untuk restore
  • Excel — format spreadsheet untuk dibaca

11.2 Restore

Upload file ZIP → "Restore dari ZIP" → sistem upsert data (tidak hapus data existing).

12. Fitur Tambahan

12.1 Peta Blok Interaktif

Grid kartu blok dengan warna: Hijau (aktif), Kuning (kurang), Abu-abu (tidak aktif). Filter per afdeling.

12.2 Dark Mode

Toggle 🌙/☀️ di pojok kanan atas. Tersimpan otomatis.

12.3 Audit Trail

Catat aktivitas: perubahan PIN, CRUD data master, export laporan. Filter + export CSV/PDF.

12.4 Demo Data

Panel Admin → Tenants → "Demo Data". Menghasilkan data demo 365 hari untuk testing.

13. Panel Admin (Super Admin)

Akses: Super Admin — link "Panel Admin" di sidebar.

13.1 Dashboard Admin

Statistik: Total Tenant, Tenant Aktif, Total User, grafik tenant baru, transaksi harian, distribusi paket.

13.2 Manajemen Tenant

Daftar perusahaan, generate Demo Data, hapus tenant.
